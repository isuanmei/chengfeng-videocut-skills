# 纪录片分镜 Skill 使用说明

这个 Skill 用于把纪录片旁白、口述史、人物回忆和纪实故事，转换为可直接用于即梦、可灵生成分镜图和视频的专业分镜表。

## 1. 安装

从当前 GitHub 仓库安装扩展版：

```bash
npx chengfeng-videocut-skills install \
  --repo https://github.com/isuanmei/chengfeng-videocut-skills.git
```

只安装到 Codex：

```bash
npx chengfeng-videocut-skills install \
  --target codex \
  --repo https://github.com/isuanmei/chengfeng-videocut-skills.git
```

只安装到 Claude Code：

```bash
npx chengfeng-videocut-skills install \
  --target claude \
  --repo https://github.com/isuanmei/chengfeng-videocut-skills.git
```

也可以克隆仓库后直接运行安装器：

```bash
git clone https://github.com/isuanmei/chengfeng-videocut-skills.git
cd chengfeng-videocut-skills
node bin/cli.js install --target codex
```

## 3. 推荐调用模板

```text
用 chengfeng-videocut-skills:纪录片分镜处理下面的纪录片旁白。

要求：
1. 生成约 60 个镜头。
2. 单镜头按叙事需要设置为 5 至 15 秒，不平均分配。
3. 画面内容写成可直接用于即梦、可灵的完整静态提示词。
4. 动态只使用简单的推、拉、摇、移。
5. 保留原文关键口述和方言质感。
6. 真实、克制、观察式、低饱和，环境声和动作声优先。
7. 同一人物跨镜头保持外形、服装和年龄阶段连续。
8. 输出 8 列 Markdown 分镜表，不附加解释。

故事正文：
……
```

## 5. 修改已有分镜

可以直接提出局部修改：

```text
继续使用 chengfeng-videocut-skills:纪录片分镜修改上一版：
1. 保留镜头编号和旁白顺序。
2. 把第 20 至 35 镜改得更生活化，减少庄严感。
3. 增加手部、呼吸、翻书和停顿细节。
4. 每条静态提示词继续保持可独立生成。
```

也可以要求整体重排：

```text
重新分配上一版镜头时长。关键顿悟段落放慢，普通找书段落压缩，总镜头数保持 60 左右。
```

## 6. 常用附加要求

### 指定画幅

```text
所有画面按 16:9 横屏纪录片构图。
```

```text
所有画面按 3:4 竖屏构图，人物避开底部字幕安全区。
```

### 指定历史质感

```text
重现场景保持 20 世纪中国乡村生活质感，无现代建筑、塑料制品、电器和现代服饰。
```

### 指定生成平台

```text
静态提示词优先适配即梦，减少模型难以稳定生成的多人复杂动作。
```

```text
图生视频提示词优先适配可灵，每个镜头只保留一个主要动作和一个缓慢运镜。
```

### 限制虚构

```text
原文未出现的人物对白不要补写。历史细节不确定时使用泛化场景，不编造具体机构、标语和事件。
```

## 7. 输出列说明

|列名|用途|
|----|----|
|镜头编号|剪辑、生成和修改时的唯一编号|
|时长|单镜头建议时长|
|景别|远景、全景、中景、近景、特写等|
|画面内容（静态）|即梦、可灵生成分镜图的完整提示词|
|画面效果（动态）|分镜图生成视频时的运镜和轻微动作|
|人物情绪|人物当下可观察、可表演的状态|
|台词和旁白|原文旁白、对白和必要精简|
|音频音效建议|环境声、动作声、呼吸声和极弱音乐建议|

## 8. 生成后的推荐工作流

```text
故事正文
  ↓
纪录片分镜 Skill
  ↓
检查人物连续性和旁白完整性
  ↓
用静态提示词生成分镜图
  ↓
统一人物和场景参考图
  ↓
用动态提示词生成视频
  ↓
按镜头编号整理素材
  ↓
进入剪辑、同期声和旁白搭建
```

第一轮先检查叙事和人物连续性。第二轮再批量生成画面。不要在分镜逻辑未稳定时大量消耗生成次数。

## 9. 适用范围

适合：

- 人物口述史
- 纪录片旁白
- 历史人物经历重现
- 修行、学习和长期积累类故事
- 人物命运转折
- 师徒传承
- 真实事件的克制重现

需要额外资料后再做：

- 精确历史服装复原
- 具体建筑和器物考据
- 多民族、多地域的精确生活细节
- 大规模战争、灾难和复杂群像调度
