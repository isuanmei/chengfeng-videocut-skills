# 纪录片分镜输出规范

## 固定表头

```text
|镜头编号|时长|景别|画面内容（静态）|画面效果（动态）|人物情绪|台词和旁白|音频音效建议|
|----|----|----|----|----|----|----|----|
```

## 镜头数量

- 默认约 60 个
- 通常为 55 至 70 个
- 短文本可减少，长文本可增加
- 用户明确指定数量时，以用户要求为准
- 镜头数量服从叙事节点，不用空镜凑数

## 时长

- 通常为 5 至 15 秒
- 关键动作、转折、顿悟和情绪停顿可以更长
- 过渡和细节可以更短
- 整张表统一使用 `8s` 或 `0-8s` 格式
- 不平均分配时长

## 景别

允许使用：

- 远景
- 全景
- 中景
- 近景
- 特写
- 俯拍中景
- 俯拍特写

景别要服务叙事：

- 远景和全景交代环境、处境和人与空间关系
- 中景呈现行动和人物关系
- 近景呈现反应和状态变化
- 特写呈现手、眼神、呼吸、书页、器物等关键细节

## 静态提示词结构

推荐顺序：

```text
影像类型 + 年代地域 + 场景 + 时间天气光线 + 人物设定 + 动作状态 + 道具细节 + 构图位置 + 景别焦段 + 色彩质感 + 排除项
```

示例：

```text
写实纪录片重现场景，20世纪上半叶中国北方山间道观，深夜油灯下，17岁瘦削年轻道士穿磨旧青灰道袍，伏在粗糙木桌前逐字抄写残旧线装经书，左侧摊着原书，右侧堆着手抄稿，人物位于画面右侧，左侧保留暗部留白，35mm纪录片构图，自然低饱和色调，真实纸张和布料质感，无现代物品，书中文字建议后期准确叠加。
```

每条必须明确主体和动作。避免：

```text
表现他多年寻找答案。
```

改为：

```text
同一间旧书房和同一张木桌，道士从青年逐渐变为中年和老人，桌上经书与批注逐年增加，窗外春雨、夏光、秋叶和冬雪依次变化，他始终停在同一句经文前沉思。
```

## 人物连续性

首次出现时完整描述人物。后续仍需保留关键识别词：

```text
17岁瘦削年轻道士，短发，青灰旧道袍，布鞋
```

不要在相邻镜头中随意改变：

- 发型
- 胡须
- 年龄
- 身材
- 服装颜色
- 主要道具
- 场景结构

重要人物存在多个年龄阶段时，先在内部建立人物卡，再写分镜。

## 动态提示词

只设置一个主运镜：

```text
推：从书页缓慢推向人物困惑的眼睛，人物保持轻微呼吸，油灯火焰自然晃动。
```

```text
拉：从人物近景缓慢拉开，显出空旷山顶和远处云海，道袍衣角被风轻轻吹动。
```

```text
摇：从桌上的手抄本缓慢摇向印刷本，最终停在两处不同文字上。
```

```text
移：沿药铺木柜缓慢横移，最终停在认真记录药名的少年身上。
```

禁止：

- 快速环绕
- 无人机俯冲
- 多次快速变焦
- 复杂一镜到底
- 大幅度镜头旋转
- 与静态画面无关的角色动作

## 人物情绪

情绪必须具体：

```text
紧张，强装镇定
困惑，仍不肯放下
震动，逐渐领悟
疲惫，心里踏实
```

情绪要通过动作可见：

- 手指扣紧
- 眼神停住
- 呼吸变重
- 话到嘴边停下
- 放下书后长呼吸
- 拒绝钱袋后转身收拾器具

## 台词和旁白

- 关键原话完整保留
- 重复口语可以轻度压缩
- 方言和人物口气尽量保留
- 补充对白必须谨慎
- 旁白顺序要与原文叙事顺序一致
- 同一句旁白可跨多个镜头，但不能无故改写含义

## 声音

每个镜头优先选择一至三种声音：

- 当前场景环境声
- 当前动作的真实声音
- 人物呼吸、停顿和身体声音

声音应与画面同步，避免每格都机械写相同风声和鸟鸣。

## 文字与标识

生成模型难以稳定生成准确汉字。出现以下内容时，写明“建议后期准确叠加”：

- 书名
- 经文
- 介绍信
- 牌匾
- 文件标题
- 年代字幕
- 地点字幕

## 结尾

结尾优先使用人物行动、空间关系或传承动作收束。避免强行补写总结性金句。原文没有结尾旁白时，可以保留环境声结束。
