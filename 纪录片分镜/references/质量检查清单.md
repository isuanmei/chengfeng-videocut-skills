# 纪录片分镜质量检查清单

交付前逐项检查。

## 原文完整性

- [ ] 时间线顺序正确
- [ ] 关键事件没有遗漏
- [ ] 关键人物关系正确
- [ ] 重要原话和方言质感得到保留
- [ ] 没有编造改变人物形象的对白
- [ ] 没有增加原文无法支持的结论

## 叙事结构

- [ ] 开头能快速建立人物、处境或核心问题
- [ ] 每个段落都有清楚的行动和因果
- [ ] 冲突、转折和顿悟获得足够镜头
- [ ] 普通过渡没有占用过多镜头
- [ ] 结尾与原文落点一致
- [ ] 空镜承担明确功能，没有凑数

## 镜头数量与时长

- [ ] 默认镜头数接近 60
- [ ] 镜头时长按叙事重量分配
- [ ] 没有机械平均时长
- [ ] 关键镜头有停顿和呼吸空间
- [ ] 单镜头长度适合即梦、可灵生成

## 静态提示词

- [ ] 每条可以脱离上下文单独生成
- [ ] 年代、地域和场景明确
- [ ] 时间、天气和光线明确
- [ ] 人物年龄、身份、服装和动作明确
- [ ] 关键道具明确
- [ ] 构图、景别或焦段明确
- [ ] 风格、色彩和质感明确
- [ ] 历史场景排除了明显现代物品
- [ ] 精确文字已提示后期叠加
- [ ] 没有只写抽象概念

## 人物连续性

- [ ] 同一人物脸型、体态和发型前后一致
- [ ] 同一年龄阶段服装主色和材质一致
- [ ] 年龄变化有明确可见差异
- [ ] 主要道具前后连续
- [ ] 同一场景的空间结构没有无故变化
- [ ] 多人镜头中的位置关系清楚

## 动态提示词

- [ ] 每条只有一个主要运镜
- [ ] 只使用推、拉、摇、移
- [ ] 运镜方向和静态画面一致
- [ ] 人物动作简单且可生成
- [ ] 保留呼吸、衣角、烟雾、树叶等轻微自然运动
- [ ] 没有复杂环绕、剧烈旋转和快速变焦

## 情绪与表演

- [ ] 情绪具体且可观察
- [ ] 情绪变化与事件对应
- [ ] 没有空泛的“高级感”“故事感”
- [ ] 关键反应镜头没有被跳过
- [ ] 人物保留犹豫、停顿和真实身体状态

## 声音

- [ ] 环境声符合时间和地点
- [ ] 动作声与画面同步
- [ ] 呼吸、脚步、翻页和衣料声得到合理使用
- [ ] 音乐使用克制
- [ ] 没有广告片式、热血式或强煽情配乐建议
- [ ] 相邻镜头声音有连续性

## 表格格式

- [ ] 表头为固定 8 列
- [ ] 镜头编号连续且唯一
- [ ] 时长格式统一
- [ ] 没有缺列
- [ ] 无内容统一写 `----`
- [ ] 最终只输出表格
