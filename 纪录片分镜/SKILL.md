# 纪录片分镜

## 核心任务

把用户提供的纪录片旁白、采访口述、人物回忆、历史叙事或纪实故事，转换为可执行的专业分镜表。

输出同时服务三个环节：

1. 纪录片叙事设计
2. 即梦、可灵等工具生成分镜图
3. 分镜图继续生成视频并进入剪辑

## 默认调用方式

用户可以直接说：

```text
用 chengfeng-videocut-skills:纪录片分镜，把下面这段旁白做成约 60 个镜头的分镜表。
画面用于即梦和可灵生成，保持酸梅纪录片风格。

故事正文：
……
```

调用时，先读取：

```text
references/输出规范.md
references/质量检查清单.md
```

需要向用户解释安装、参数和进阶用法时，再读取：

```text
README.md
```

## 输入

必需输入：

- 故事正文、旁白、采访口述或人物经历

可选输入：

- 目标镜头数
- 目标成片时长
- 画幅比例
- 历史年代和地点
- 人物外形参考
- 需要保留的原话
- 画面风格参考
- 禁止出现的内容
- 需要适配的生成平台

用户没有给出可选信息时，使用本 Skill 的默认规则，不要反复追问。

## 工作流程

### 1. 锁定原文

先提取：

- 时间线
- 人物身份与关系
- 关键事件
- 行动因果
- 情绪转折
- 必须保留的原话
- 结尾落点

不得擅自改变事实、人物关系和原文观点。可以精简重复表达，可以补充无台词的过渡镜头，不得编造关键事件和关键对白。

### 2. 建立人物连续性

同一人物跨镜头必须保持一致：

- 年龄阶段
- 脸型、体态和发型
- 服装主色和材质
- 身份特征
- 常用道具

人物跨年龄出现时，保留可识别的骨相和体态关系，同时明确少年、青年、中年、老年的差异。

### 3. 按叙事重量分配镜头

默认生成约 60 个镜头，通常控制在 55 至 70 个之间。

镜头数量按内容分配：

- 重要冲突和转折，多给镜头
- 长时间积累，用动作细节和时间变化表达
- 关键顿悟，保留反应和停顿
- 普通过渡，减少镜头
- 不平均切分句子

单镜头通常为 5 至 15 秒。时长服从叙事节奏，不强行平均。

### 4. 设计镜头层次

每个段落优先组合以下镜头：

- 环境建立镜头
- 人物状态镜头
- 行动过程镜头
- 手部、眼神、呼吸、物件等细节镜头
- 情绪反应镜头
- 因果衔接镜头
- 留白镜头

空镜必须承担时间、空间、情绪或转场功能。禁止用无意义风景填数量。

### 5. 写静态画面提示词

“画面内容（静态）”必须能够脱离上下文单独使用，并直接投喂即梦、可灵生成分镜图。

每条尽量写清：

1. 年代与地域
2. 具体场景
3. 时间、天气和光线
4. 人物年龄、身份、外形和服装
5. 人物动作与身体状态
6. 关键道具
7. 人物在画面中的位置
8. 景别、镜头焦段或构图
9. 色彩和影像质感
10. 需要排除的现代物品或夸张效果

推荐句式：

```text
写实纪录片重现场景，20世纪上半叶中国北方山间道观，清晨薄雾，17岁瘦削年轻道士穿磨旧的青灰色道袍，独自盘坐在青石院落中央，双手自然放在膝上，远处木建筑陈旧，人物较小，环境占画面大部分，24mm广角，自然低饱和色调，真实粗粝质感，安静克制，无现代物品。
```

涉及书名、牌匾、信件、经文等精确文字时，提示“文字建议后期准确叠加”，不要依赖生成模型直接写对文字。

### 6. 写动态提示词

“画面效果（动态）”用于图生视频，只设置一个主要镜头运动。

只使用：

- 推
- 拉
- 摇
- 移

推荐格式：

```text
推：从昏暗书房缓慢推向老人停在书页上的手指。
拉：从人物近景缓慢拉开，显出山路和远处道观。
摇：从经书上的关键字缓慢摇向年轻道士困惑的眼睛。
移：沿旧书架缓慢横移，最终停在正在寻找经书的人物身上。
```

动态保持缓慢、稳定、单纯。可以补充人物呼吸、衣角、烟雾、树叶等轻微自然运动。禁止复杂环绕、快速穿越、剧烈变焦和炫技调度。

### 7. 处理人物情绪

情绪要写成当下可表演、可观察的状态：

```text
少年：困惑，执着
年轻道士：紧张，强装镇定
老人：震动，逐渐释然
妇人：崩溃，抓住最后希望
```

避免只写“复杂”“高级”“有故事感”等无法执行的词。

### 8. 处理台词和旁白

优先保留原文中的关键句、人物口气和方言质感。

规则：

- 原文旁白标注“旁白：”
- 人物对白标注人物名
- 可以适度精简重复句
- 不遗漏叙事关键信息
- 不随意补充改变人物形象的对白
- 无内容时写“----”

### 9. 设计声音

声音优先级：

```text
同期动作声与呼吸声 > 环境声 > 空间声 > 极弱音乐
```

优先使用：

- 山风、虫鸣、鸟叫、鸡叫、雨声、远犬吠
- 翻页、写字、脚步、衣料、木门、桌椅、器具碰撞
- 呼吸、停顿、咳嗽、抽泣、轻声交谈
- 道观钟声、木鱼、油灯、香火等真实空间声音

音乐仅在情绪转折确有需要时写“极弱氛围音乐铺底”或“低沉克制配乐轻入”。避免热血、宏大、广告片式和强煽情配乐。

## 酸梅纪录片风格

默认遵守：

- 真实优先于完美
- 人物变化优先于场面展示
- 行动因果优先于概念包装
- 同期声、呼吸声和环境声优先于音乐
- 保留犹豫、停顿、笨拙、失败、等待和恢复
- 镜头克制，适度留白
- 轻微电影感，保持生活质感
- 避免花哨转场、假励志、纯炫技快剪和网感包装
- 光线和构图必须符合人物当下情绪

## 输出格式

最终只输出以下 8 列 Markdown 表格：

```text
|镜头编号|时长|景别|画面内容（静态）|画面效果（动态）|人物情绪|台词和旁白|音频音效建议|
|----|----|----|----|----|----|----|----|
```

允许景别：

- 远景
- 全景
- 中景
- 近景
- 特写
- 俯拍中景
- 俯拍特写

表格规则：

- 镜头编号连续且唯一
- 时长使用 `8s` 或 `0-8s`，整张表保持一致
- 没有内容的格子统一写 `----`
- 画面内容必须为完整提示词
- 动态提示只保留一个主运镜
- 最终不附加解释、总结或重复全文

## 特殊内容处理

### 梦境、神秘体验和宗教体验

尊重讲述者的主观经验。画面保持克制，通过光线、声音、空间和人物反应表达，避免廉价光效、神像化人物和夸张玄幻特效。

### 时间跨度

优先使用同一地点、同一动作、书页磨损、批注变化、服装变化、季节变化、人物衰老等可见线索。避免只靠字幕交代几十年。

### 历史重现

若原文没有提供精确年代、地点或服饰资料，使用稳妥的泛化表达，不虚构具体政治标语、机构名称和历史事件细节。

### 文字和典籍

准确书名、经文、牌匾和介绍信内容建议后期叠加。画面生成提示中强调纸张、装订、笔迹和使用痕迹。
